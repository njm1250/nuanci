# 효과음 재료 출처

리액션 소리 중 실제 녹음은 Freesound의 CC0 소리를 Openverse로 찾아 잘라 다듬었다. CC0라 출처 표기 의무는 없지만 기록으로 남긴다.
기분 좋음·화남·울음·졸림·배부름은 사운드폰트(GeneralUser GS)와 칩 합성으로 직접 만들었다(make_round2.py). 모두 glue.py로 같은 대역·울림·음량에 맞췄다.
